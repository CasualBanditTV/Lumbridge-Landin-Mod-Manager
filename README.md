## ✨ Features

- 🎮 **Mod Management** — Manage your game mods.
- 🔄 **Automatic App Update Checks** — Checks for newer app versions.
- 📦 **Update Packages** — Supports distributing app updates.
- 🛠️ **Fixes and Improvements** — Makes future updates easier to distribute.
- 🛡️ **Startup Options** — Supports startup and background notifications when configured.

## 🔄 How Updates Work

1. 🚀 Launch Lumbridge Landin Mod Manager.
2. 🌐 The app checks the online version information.
3. 🆕 If a newer version is available, an update prompt appears.
4. 📥 Choose **Update App** or **Keep Current Version**.

If the online version check fails, the app should continue opening normally.
