## 🎮 About

Welcome to **Lumbridge Landin Mod Manager**, a mod management tool for *RuneScape: Dragonwilds*.

This repository provides public app downloads and supports distributing application updates through the built-in updater.

## 📥 Download the Latest Version

Ready to get started? 🐉

**[⬇️ Download Lumbridge Landin Mod Manager](https://github.com/CasualBanditTV/Lumbridge-Landin-Mod-Manager/releases/latest)**

1. Open the latest release.
2. Download the installer or ZIP package under **Assets**.
3. Run the installer or follow the included installation instructions.
4. Launch the app and manage your mods!

> ⚠️ A release package must be published before the download link will provide a download.

## ✨ Features

- 🎮 **Mod Management** — Manage mods for RuneScape: Dragonwilds.
- 🔄 **App Update Checks** — Check for newer application versions.
- 📦 **Update Packages** — Distribute application updates.
- 🛠️ **Fixes and Improvements** — Receive improvements through future releases.
- 🛡️ **Startup Options** — Startup and background notification features when configured.

## 🔄 How App Updates Work

1. 🚀 Launch the mod manager.
2. 🌐 The app checks the online application version.
3. 🆕 If a newer version is available, an update prompt appears.
4. 📥 Select **Update App** to update or **Keep Current Version** to continue using your existing version.

If the online version check fails, the app is intended to continue opening normally.
