🎮 About
Lumbridge Landin Mod Manager is an application created by CasualBanditTV specifically for the private Lumbridge Landin server in RuneScape: Dragonwilds.
The app helps players manage their mods and check for application updates.
🌍 About the Server
- 🏰 World: Lumbridge Landin
- 🎮 Game: RuneScape: Dragonwilds
- 🔒 Access: Private
- 🔑 Joining: Invite code or world password
🛡️ How to Get Access
1. 🎮 Ask a Friend — Contact a friend who already has access to the world and ask for an invite code or the world password.
2. 👑 Contact an Admin — If you don't know anyone with access, contact a server admin for help.
3. 🌍 Join the World — Use either a valid invite code or the world password to access Lumbridge Landin.
⚠️ Important: Lumbridge Landin is a private world. You must obtain an invite code or the password from a friend with access or a server admin. Please don't share private access details publicly.

📥 Install the Mod Manager
You do not need to manually download the latest application release.
The recommended way to install the Lumbridge Landin Mod Manager is to download and run installer.bat from this repository.
🚀 How Installation Works
1. 📥 Download installer.bat from this repository.
2. ▶️ Run the installer.
3. 🌐 The installer checks GitHub for the latest published release.
4. 🏷️ It checks the latest release version tag.
5. 🔍 If the Mod Manager is already installed, the installer reads its InstalledVersion.txt.
6. 🆕 If the installed version is missing or older than the latest release, the installer downloads the latest application package.
7. 📦 The installer extracts the package and installs the Lumbridge Landin Mod Manager folder into the correct location.
8. 🖥️ The installer creates or repairs the Lumbridge Landin Mod Manager desktop shortcut.
9. 🧹 Temporary downloaded files are cleaned up after installation.
10. 🎮 Launch the Mod Manager from the desktop shortcut.
💡 Why Use the Installer?
The installer is designed so players don't have to manually manage application releases.
You don't need to:
- Search through GitHub Releases.
- Manually choose which application ZIP to download.
- Extract the application files yourself.
- Manually replace an older installation.
- Manually create the desktop shortcut.
The installer handles these tasks automatically.
Players should normally download installer.bat from the main repository.

🔄 How App Updates Work
There are two parts to the update system.
🛠️ Installer Updates
When you run installer.bat, it checks the latest GitHub Release.
For example:
InstalledVersion.txt
v1.0.0

Latest GitHub Release
v1.1.0
If the versions are different, the installer downloads the latest application package and replaces the existing Lumbridge Landin Mod Manager installation with the newer version.
If the versions match:
InstalledVersion.txt
v1.0.0

Latest GitHub Release
v1.0.0
the installer recognizes that the latest version is already installed and does not download the application again.
📱 In-App Updates
The Mod Manager is also being designed to detect newer application releases while the app is running.
The intended process is:
1. 🚀 Launch the Mod Manager.
2. 🌐 The app checks the latest GitHub Release.
3. 🏷️ It checks the latest release version.
4. 🆕 If a newer version is detected, the app can notify the player.
5. 📥 The update system will use the latest Lumbridge.Landin.Mod.Manager.zip application package from GitHub Releases.
6. 🔄 The player can update the application without manually searching through GitHub.
⚠️ Current status: The in-app update system is currently being developed and is not yet fully functional.

If the online version check fails, the app is intended to continue opening normally.
📦 GitHub Releases
GitHub Releases are used to publish the actual application files for the Mod Manager.
The current application package is published as:
Lumbridge.Landin.Mod.Manager.zip
The installer uses the latest published release to obtain the application files.
Players generally do not need to visit the Releases page manually. The normal installation method is to download and run:
installer.bat
The Releases section is primarily used as the distribution location for the latest application package.
