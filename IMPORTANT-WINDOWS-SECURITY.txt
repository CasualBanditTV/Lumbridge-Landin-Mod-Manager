https://github.com/CasualBanditTV/Lumbridge-Landin-Mod-Manager

------------------------------------------------------------
CURRENT MICROSOFT DEFENDER DETECTION
------------------------------------------------------------

Microsoft Defender has detected the installer with:

Trojan:Script/Wacatac.H!ml

This detection has been submitted to Microsoft for analysis
as a suspected false positive.

The installer uses a Windows batch file and PowerShell to:

- Check the latest Lumbridge Landin Mod Manager release.
- Connect to the official GitHub repository.
- Download the current application package.
- Extract the application files.
- Install or update the application.
- Create or repair the desktop shortcut.

These actions are part of the install/update process.

------------------------------------------------------------
IF WINDOWS BLOCKS THE INSTALLER
------------------------------------------------------------

DO NOT disable Microsoft Defender permanently.

If you downloaded installer.zip from the official
Lumbridge Landin Mod Manager GitHub repository and want to
continue, you can check Windows Security's Protection History.

1. Open Windows Security.

2. Select:
   Virus & threat protection

3. Under "Current threats", select:
   Protection history

4. Find the detection associated with:

   Lumbridge Landin Mod Manager

   or:

   Trojan:Script/Wacatac.H!ml

5. Expand the detection.

6. Select "Actions" if that option is available.

7. If Windows provides the option, select:

   Allow on device

------------------------------------------------------------
AFTER ALLOWING THE FILE
------------------------------------------------------------

If Windows removed the installer, download installer.zip
again from the official GitHub repository.

Then:

1. Extract installer.zip.

2. Open the extracted "installer" folder.

3. Run:

   installer.bat

The installer will then check the latest official GitHub
release and install the current version of Lumbridge Landin
Mod Manager.
